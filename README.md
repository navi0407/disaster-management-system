# Disaster Management System

Final project for Software Engineering. PHP + MySQL, built with XAMPP.

## Setup

1. Copy this whole folder into your XAMPP `htdocs` directory.
2. Start Apache and MySQL from the XAMPP control panel.
3. Open phpMyAdmin (or MySQL Workbench) and create a database named `dms_db`.
4. Visit `http://localhost/disaster-management-system/` in your browser.
5. You should see "Database connection: successful" on the homepage.

## Folder structure

- `config/` — database connection settings
- `includes/` — shared header/footer used across every page
- `assets/` — CSS and JS
- `index.php` — homepage
